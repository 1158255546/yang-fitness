# 首版（MVP）验收清单 — 组间休息计时

配套可行性结论见 [watch-rest-timer-feasibility.md](./watch-rest-timer-feasibility.md)。

## MVP 范围（固定）

| # | 能力 | 通过标准 |
|---|------|----------|
| 1 | iPhone 发起休息 | 提供 **60 / 90 / 120s** 预设；点选后向 Watch 发送 start + duration |
| 2 | Watch 本地倒计时 + 触觉 | Watch 显示剩余秒数；到 0 时播放**强触觉**（不等待 iPhone 消息） |
| 3 | 锁屏 / 垂腕准时 | Phone 锁屏、Watch 垂腕后再抬腕，触觉仍相对设定终点 **约 ±1s** |
| 4 | 取消 / 提前结束 | iPhone 或 Watch 可 cancel；倒计时停止且**不**误触到点触觉 |

**非 MVP：** 云同步、社交、完整训练计划、App Store 上架、以 iPhone 通知为主路径的提醒。

## 真机测试矩阵

| 用例 | 前置 | 操作 | 期望 | 仅真机？ |
|------|------|------|------|----------|
| 基础到点 | Watch 佩戴；Workout 或 Extended 会话已启 | Phone 选 60s 开始 | Watch 倒计时；约 60s 后强触觉 | **是**（触觉/佩戴） |
| Phone 锁屏 | 同上；开始后立刻锁 iPhone | 等待结束 | 仍准时触觉；不依赖 Phone 前台 | **是** |
| Watch 后台 | 开始后切走 Watch App 或垂腕灭屏 | 等待结束 | 后台仍到点触觉 | **是** |
| 中途取消 | 计时进行中 | Phone 或 Watch 点取消 | 立即停止；无到点触觉 | 逻辑可部分在模拟器；取消后无触觉需真机 |
| 90s / 120s 预设 | 同上 | 各跑一轮 | 时长与预设一致（±1s） | 时长可用模拟器粗测；触觉需真机 |
| 勿扰 / 剧院 | 系统开启 DND 或剧院模式 | 跑一轮到点 | 可能无触觉或减弱 | **是**；记为**已知限制**，非阻断 |

## 模拟器 vs 真机

| 可在模拟器做的 | 必须真机 |
|----------------|----------|
| UI 布局、预设按钮、cancel 状态机 | 锁屏 + 后台准时触觉 |
| WCSession 消息形状（有限） | 佩戴感、垂腕再抬腕 |
| 本地 Timer 数字递减 | Workout / Extended 实机耗电与会话行为 |
| — | DND / 剧院对触觉的抑制 |
